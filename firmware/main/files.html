JSON files become new, timestamped versions in config/ (16 KiB each). WAV files go into sounds/ (16 MiB each). WAV names use ASCII letters, numbers, spaces, underscores, hyphens and periods. An IERS leap-seconds.list replaces time/leap-seconds.list only if its SHA-1 line verifies. A file named wifi.json replaces the write-only secrets/wifi.json; it cannot be downloaded or edited here.
